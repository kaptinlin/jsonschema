# Specifications

`SPECS/` owns durable behavioral contracts for jsonschema. User tutorials belong
in `README.md` and `docs/`; implementation plans and completion evidence do not
belong here.

| Document | Owns |
|----------|------|
| [01-exact-json-numbers.md](01-exact-json-numbers.md) | Untyped JSON number representation, numeric normalization, JSON equality and hashing, unmarshaling, and custom codec ownership. |
| [02-format-vocabularies.md](02-format-vocabularies.md) | Format annotation and assertion policy, lookup precedence, failures, output annotations, and schema-resource inheritance. |
| [03-compilation-lifecycle.md](03-compilation-lifecycle.md) | Completed reference graphs, resource identity, publication, failure isolation, and constructor composition. |
